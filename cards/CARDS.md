# Learning Cards

Each card has four layers: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Plus the gap evidence.

---

## 迭代经济学

> 花了多少、换回多少？不算这笔账，越忙越亏。

### L48 · 每洞见成本

`token-per-insight` · `components/L48-token-per-insight/`

- **L0（人话）** 说了半天，有几个真正新的点？把花掉的钱除以「新点个数」，才知道这轮值不值。
- **L1（本质）** 洞见先去重（重复三遍不算三个），再算 token/洞见。特别规则：洞见为 0 时成本是纯消耗——这是唯一需要立刻停的情况。
- **L2（怎么用）** 每轮结束算一次；>2000 token/洞见就该改方法，而不是加轮次。
- **边界** 「洞见」需人工定边界；重复表述当新洞见会低估成本。
- **空白证据** 成本看板管花费，缺「以新洞见为分母」的效率口径（抽样 29 条邻域）。

### L49 · 信息价值闸

`value-of-information-gate` · `components/L49-value-of-information-gate/`

- **L0（人话）** 查一个资料要花时间，但如果查到了你也不会改主意，那这个资料就不值得查。
- **L1（本质）** 期望价值 = 会改主意的概率 × 决策影响 − 查证成本，净值为负就不查。核心判据：改变决策的概率为 0 时，信息价值恒为 0，与好不好查无关。
- **L2（怎么用）** 查证前先问「知道了会改吗」；答不出就跳过这条。
- **边界** 三个输入全是估计；它只帮你排序，不给结论。
- **空白证据** 决策理论有 VOI 概念，缺 20 行可调用版本（抽样未单列）。

### L50 · 摊销规划

`amortization-planner` · `components/L50-amortization-planner/`

- **L0（人话）** 花一天做个工具，如果以后只用两次就不值；用二十次就很值。这工具算回本点。
- **L1（本质）** 回本点 = 一次性投入 / 每次节省。每次不省则永远不回本（never-pays），这是最该早停的一类投入。
- **L2（怎么用）** 决定「要不要造轮子」前算一次；回本点远大于预计使用次数就买现成的。
- **边界** 假定使用次数可估；估高了会造出没人用的轮子。
- **空白证据** 财务有摊销概念，缺「按使用次数判建造成本」的判定（抽样未单列）。

### L51 · 沉没成本断路

`sunk-cost-breaker` · `components/L51-sunk-cost-breaker/`

- **L0（人话）** 已经花了一万块，不代表还要继续花。真正该问的是：从现在起，再投一千块能不能赚回来。
- **L1（本质）** 只看未来净收益 = 成功率×剩余期望 − 完工成本；已花的不进公式。这不是冷酷，是唯一正确的算法——把沉没成本算进去，只会在错误方向上越走越远。
- **L2（怎么用）** 每次「要不要继续」的判断都跑一次；verdict=stop 就停，别用「都做到这里了」说服自己。
- **边界** 剩余期望是估计值；它对「期望本身有偏」无能为力。
- **空白证据** 决策理论有沉没成本谬误，缺「可随时调用的断路器」（抽样未单列）。
